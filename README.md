# React Portfolio

A modern, interactive portfolio website built with React, TypeScript, and Vite. Features a dynamic resume page with dark/light mode toggle and animated visual effects.

## Features

- Interactive resume with expandable sections
- Dark/Light theme toggle
- Responsive design for all devices
- Animated dithering background effect
- Professional project showcase
- Document viewer for certifications

## Tech Stack

- React 19
- TypeScript
- Tailwind CSS
- Vite
- @paper-design/shaders-react

## Getting Started

1. Clone the repository
```bash
git clone https://github.com/AbdulazizBaHaj/react-portfolio.git
cd react-portfolio
```

2. Install dependencies
```bash
npm install
```

3. Run development server
```bash
npm run dev
```

4. Build for production
```bash
npm run build
```
